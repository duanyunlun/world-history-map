# 世界历史地图（前10000 — 2026）

以「全国地图 + 事件」的交互方式呈现**全球**政治地理的时间演变：可拖动时间轴、点击地块看
该地在当时由谁控制、点击事件看经过与来源。**中国部分保留逐月精度（1893.01—1976.12）**，
其余世界按时间切片（远古）与逐年（1977 后）呈现。

## 中国部分的时间覆盖

| 时期 | 精度 | 说明 |
|---|---|---|
| 前1600—前771 | 逐年 | 商·西周（王畿与方国/诸侯；口径为“主要控制或文化归属”，仅供大势参考） |
| 前770—前221 | 逐年 | 春秋·战国（周王室、晋齐楚秦燕吴越与战国七雄、巴蜀、百越等） |
| 前221—公元219 | 逐年 | 秦·汉（郡县制；匈奴/南越/闽越/滇/夜郎/西域诸国并立） |
| 220—617 | 逐年 | 三国·两晋·南北朝·隋（魏蜀吴→西晋→东晋十六国→南北朝→隋） |
| 618—959 | 逐年 | 唐·五代十国（含吐蕃据河西、南诏、渤海、回鹘与十国） |
| 960—1270 | 逐年 | 宋辽夏金（含蒙古兴起） |

## 开发流程（一条命令）

```bash
scripts/pipeline.sh              # 数据校验 → 构建 → 自检 → 真实鼠标 → 部署 → 打包
scripts/pipeline.sh --geo        # 改过历史区划/割据区数据时，额外重建中国几何
scripts/pipeline.sh --world      # 改过县级边界缓存时，额外重建世界切片
scripts/pipeline.sh --no-deploy  # 快速迭代：跳过 Docker 与打包
```

顺序写死在脚本里，避免「先验证后构建」「改了数据没重跑 build_geo」这类时序错误——
此前这类错误多次导致验证的其实是旧产物。**校验未通过会立即中断**，不会构建出坏产物。

批量补录世界事件请用 `scripts/add_events.py`（批内去重 + 写入条数报告 + 强制校验）。

## 数据校验（每次批量补录后必跑）

```bash
python3 scripts/check_data.py --stats
```

校验内容：世界事件（必填字段、年份/月份/经纬度范围、来源为 http(s)、重复项、分类合法性）、
政体详情（存续期不倒置、来源合法、是否出现在时间切片中）、世界切片（年份排序、
覆盖公元前10000年至2014年后、几何引用有效）。**有错误即退出码非 0**。

之所以加这一步：此前多次出现「批量补录脚本参数写错 → 整批未写入但表面成功」的情况，
现在补录后立即校验，2026 年这次即查出 3 处真错误（哥贝克力石阵年份越界、重复事件、
最晚切片判定过严）与 17 条“写了简史却与数据集命名对不上”的条目。

## 全局覆盖审计（可复现）

在浏览器控制台执行以下代码即可复核（也可用 `scripts/cdp_shot.js` 注入）：

```js
// 每个时间步只能属于一个区间
let multi=0,none=0;
for (let i=0;i<A.TL.steps.length;i++){let n=0;A.TL.ranges.forEach(r=>{if(i>=r.from&&i<=r.to)n++;});if(n>1)multi++;if(!n)none++;}
// 中国逐年覆盖是否连续
const y=A.TL.steps.filter(z=>z.kind==='cny').map(z=>z.y);
console.log(multi,none,Math.min(...y),Math.max(...y),y.length);
```

当前结果：时间轴 **3889 步 / 12 区间**，区间重叠 0、未覆盖 0；
中国逐年 **前1600—公元1892 连续 3493 年**，1893—1976 逐月 1008 步；
世界切片 180 个（前123000—2026）、政体几何 4846 个；世界事件 808 条、中国事件 931 条。

# 中国历史地图 · 1893—1976

一个**全国范围、逐月演进**的可交互历史地图站点：以中国省级行政单元为底板，
按**月**为刻度展示 1893 年 1 月至 1976 年 12 月（共 **1008 个月**）各地实际控制政权／势力范围的变化，
并把同一时期发生在各地的大事挂在地图上，可点击下钻查看完整说明与相关人物生平。

站点为**单文件、完全本地化**：`index.html` 内联全部地图几何、史料数据与逻辑，双击即可离线打开，
不依赖任何 CDN、字体或外部接口。人物生平与事件详情均在**当前页面内**跳转，不跳出站点。

---

## 一、功能

### 1. 地图与势力范围（逐月动态）
- 34 个省级单元（含台港澳），Albers 等积投影，按省级行政单元着色。
- 着色不是静态的：`1893 年清王朝 → 1916 年军阀割据 → 1928 年南京国民政府 → 1937 年日伪与抗日根据地并存
  → 1945 年国民政府接收 → 1949 年 10 月中华人民共和国 → 1951 年西藏和平解放`，
  拖动时间轴即可看到地块颜色逐月变化。
- 除按年划分的归属区间（212 段）外，另设 **170 个月级关键切点**，用于精确到月的转折：
  九一八（1931.09）、七七（1937.07）、南京陷落（1937.12）、武汉沦陷（1938.10）、汪伪成立（1940.03）、
  东北苏军占领（1945.08）、台湾光复（1945.10）、辽沈（1948.11）、北平和平解放（1949.01）、
  渡江（1949.04）、上海解放（1949.05）、建国（1949.10）、海南岛（1950.05）、西藏和平解放（1951.05）等。
- 悬停显示该地该月归属与依据；图例实时显示当月各方控制了哪些省份。

### 2. 周边国家底图（随时间变色）
- 画布内一并绘制 **24 个周边国家/地区**（俄罗斯、蒙古、中亚三国、阿富汗、巴基斯坦、印度、尼泊尔、不丹、
  孟加拉国、斯里兰卡、缅甸、泰国、老挝、越南、柬埔寨、马来西亚、文莱、印度尼西亚、菲律宾、日本、朝鲜、韩国）。
- 邻国同样**按时间点着色**，表示其当时的政权或占领方，随月份变化，例如：
  `日本：大日本帝国 → 盟军占领（1945.9）→ 日本国（1952.5）`；
  `朝鲜半岛：朝鲜王朝 → 日本统治（1910.8）→ 盟军军政（1945.9）→ 朝鲜/韩国（1948）`；
  `蒙古：清王朝 → 自治（1911.12）→ 北洋收复（1919.11）→ 蒙古人民共和国（1924.11）`；
  `东南亚：英/法/荷殖民地 → 日本占领（1941—1942）→ 独立（1940 年代末—1950 年代）`。
- 邻国仅作地理参照与势力对比，**不含事件数据**（后续规划）。

### 2.5 全国性事件单独标识
条约外交、中央政府决策、全国性运动等**不隶属单一地点**的事件，钉在某个省上会误导，
因此构建期判定 `scope`（全国性 / 地方性）并单独呈现：

- 地图**顶部居中**出现「★ 事件名」芯片，点击即打开详情，悬停显示概要；无此类事件时该栏自动隐藏；
- 这类事件**不再作为省份光点**（光点只表示地方性事件），侧栏卡片上带「全国」标识；
- 判定规则：地点在国外且属外交/全国性措辞、地点为首都且标题属中央政府行为或全国运动、
  地点即写「全国/各地」；数据中可用 `"scope": "nation"` 显式指定覆盖。
- 现共 **164 条**全国性事件（约占 18%），如《马关条约》签订、戊戌变法、开国大典、
  第一届全国人大与宪法、五一六通知、中国恢复联合国席位、抗美援朝等。

### 3. 割据区 / 根据地（跨省、按县）
省级填色只表示"该省该月由谁控制"，但历史上许多势力是**跨省且只占部分县**的
（中央苏区横跨赣南闽西、陕甘宁边区只占陕北陇东一部分、各抗日根据地按县分布）。
为此另设一层**按县组合**的割据区图层，随月份显隐，可与省级填色叠加查看：

| 时期 | 区域 |
|---|---|
| 1927—1930 | 井冈山、海陆丰、左右江 |
| 1930—1934 | 中央苏区、鄂豫皖、湘鄂西（洪湖）、川陕、湘鄂川黔、鄂豫陕 |
| 1927—1950 | 琼崖 |
| 1937—1945 | 陕甘宁边区、晋察冀、晋绥、晋冀鲁豫、山东、苏中苏北、鄂豫边、东江 |
| 1938 后 | 各抗日根据地并存 |

- 共 **18 个区域、覆盖 228 个县级单位**；点击任一区域可查看其起止时间、所辖县清单、
  历史县名与今名对照、涉及省份（可跳转到该省当月详情）。
- 图层常显；图例中**按势力归为一组**（如「中共抗日根据地 8 处」「中共苏区 1 处」），
  点击分组行才展开各根据地名称与所辖县数——同色条目不再逐条罗列。
- **省级着色不再"整省标成苏区"**：如 1931—1933 年江西省级归属仍记为国民政府
  （南昌、九江及赣中赣北确由其控制），中华苏维埃共和国的实际控制范围只由「中央苏区」图层
  按县呈现；同理 1927 年江西/湖南、1935 年陕西也不再整省标为苏区/根据地。
- **口径说明**：县界采用**现行县级行政单位**近似。1950 年代以后多有并县、改名、改区
  （如黄安→红安、龙岩县→新罗区、大庸县→永定区、六安县→金安区+裕安区），
  因此每个区域的详情里都列出"历史县名 → 今名"对照；跨省重名（如福建永定区 / 湖南永定区）
  用「省|名」限定。史料只记"某县一带"者，按今县整县近似，不作县级以下细分。

### 4. 清除内外忧患标注
顶部「清除内外忧患标注」按钮可一键隐藏当前时间点的事件标记与说明（内忧外患图层），
只留势力范围本身，便于观察某一年的势力格局；再次点击恢复。

### 5. 南海诸岛
南海诸岛直接绘制在**同一画布内**、海南岛正南，与主图使用同一 Albers 投影，因此与大陆、周边国家的
地理关系严格一致；包含东沙/西沙/中沙/南沙群岛、黄岩岛、曾母暗沙等 **125 处礁岛点位**与岛群中文标注，
顶部「南海」按钮可一键定位。

> **关于九段线**：本项目**默认不绘制九段线**。该线需贴合越南、马来西亚、文莱、菲律宾等国的海岸走向，
> 而本工程使用的 Natural Earth 110m 海岸线精度不足（巴拉望等狭窄岛体已被简化），自动贴边或手工摆点
> 都会画歪。若需绘制，请提供权威矢量数据：把 `data/nine_dash.example.json` 复制为
> `data/nine_dash.json` 并填入折线坐标（WGS84），重新构建后前端会自动绘制该图层。

### 6. 时间线
- 底部时间轴**步进为一个月**，可拖动、可点击定位；`‹ ›` 逐月，`−1年 +1年` 逐年，`«5年 5年»` 五年一档。
- 支持播放（`▶`）与**倍速下拉**（1x / 2x / 5x / 10x / 20x），`空格` 播放/暂停，`←→` 逐月，`Shift+←→` 逐年，`Esc` 返回。
- 时间轴上方是分期色带（清末 / 军阀割据 / 南京国民政府 / 全面抗战 / 解放战争 / 新中国初创 / 探索与曲折 / “文革”十年），
  下方刻度按**月**排布并以颜色深浅标出事件密集月份。

### 7. 点击地块 → 放大 + 该地详情
- 点击任一省份：镜头平滑拉近该地（约 2—15 倍），其余地块压暗、地名隐藏，右侧抽屉展开该地详情。
- 抽屉内含：该月归属政权（含依据说明）、本月该地事件、前后半年事件、以及**该地势力变迁时间表**（点击任一行可跳到对应年月）。

### 8. 点击事件 → 右侧弹入事件说明
点击事件卡片或地图上的事件标记，右侧抽屉切换为**事件详情**视图，包含：
- **时间**（精确到日；仅记到年月者标注「月份待考」）、**地点**、**当时势力**（按事件涉及的省份逐省列出该月的实际控制政权）；
- **事件详细时间线**：3—6 个关键节点，逐条给出日期与经过；
- **造成的影响**；
- **相关人物**：人物名做成可点击标签。

### 9. 点击人物 → 页内跳转人物生平
点击人物标签，**同一页面内**切换为人物生平视图：生卒年、身份职务、阵营、简介、生平正文、
**相关事件链接**（点击可跳回该事件详情）、资料来源。全程 `‹ 返回` 逐级回退，不离开站点、不联网。

### 10. 界面
- 右侧详情栏**可拖动左边缘调整宽度**，上限为页面宽度的一半。
- 顶部「事件」按钮可在未选中任何省份时手动展开侧栏，显示**当前时间点的全国事件**。
- 点击地图空白处只收起侧栏与选中态，**不会改变当前缩放**；需要回到全国视野请点「全国」或「复位」。
- 地名随缩放按 `k^0.35` 轻微放大，放大后不会变成巨字。

### 11. 来源标注（每条事件都有出处）
每条事件都带 1—3 个可点击来源链接，界面显示为「来源」标签行，链接可跳转外部页面查看原始资料；
抽屉底部固定声明数据来源与口径说明。

## 一·四、统一到「月」的数据底层
所有图层都以 `1008 个月`（1893.01—1976.12，月序号 `mi = 年×12 + 月 − 1`）为统一索引，
每处变更都记录**生效月份**，前端不再解析日期字符串：

| 图层 | 逐月表达 | 精度 |
|---|---|---|
| 省级势力 | `factions.json` 年区间 + **月级切点** → 逐月查表（1008 项） | 到月 |
| 历史区划底图 | `historical_units.json` 18 个时期，起止均到月；构建期展开为 `monthDiv[1008]` | 到月 |
| 周边国家 | `neighbors.json` 年区间 + 月级切点 → 逐月查表 | 到月 |
| 割据区 / 根据地 | 每条含 `from/to [年,月]`，逐月判定 | 到月 |
| 事件 | 构建期解析出 `mi`（绝对月序号）、`day`、`approx` 精度标记 | 到日 560 · 到月 287 · 仅到年 84 |

- 运行时提供统一入口 `stateAt(月序号)`，一次返回该月的区划集合、各省归属、周边归属、割据区与事件；
  自检断言 **1008 个月逐月状态完整**（无缺省、无空洞）。
- 区划变更全部按月生效，例如 1952.11 撤平原省与察哈尔省、1954.03 撤绥远省、1954.06 辽东辽西松江合并、
  1954.09 撤宁夏省、1955.07 撤热河省、1955.09 撤西康省、1956.04 阿拉善划归内蒙古、1969.07 内蒙古东部分隶邻省。
- **仅到年的事件不臆造月份**：暂列于本年 1 月并在界面标注「⏱ 月份待考」；
  由事件正文补出月份的标注「⏱ 月份据正文所载」，便于核对。

## 一·五、底图随时期变化（历史区划）
底图**不是**今天这张省界图，而是按时期用**县级边界重组**出来的当时省级区划：

| 时期 | 底图要点 |
|---|---|
| 1893—1913 | 清末行省与藩部：**直隶、奉天**；内蒙古为**蒙古盟旗**、青海为**办事大臣辖区**；宁夏府属甘肃；台湾省（1895 年割让） |
| 1914—1928 | 增设**热河、察哈尔、绥远、川边**四特别区；北京为京兆地方 |
| 1929—1948 | **热河、察哈尔、绥远、宁夏、青海、西康**相继设省（西康 1939 建省，含今甘孜、雅安、凉山与昌都） |
| 1949—1953 | **平原省**（豫北鲁西）、**辽东/辽西/松江省**、**内蒙古自治区**（1947 成立）、察哈尔含雁北；宁夏、西康仍在 |
| 1954—1958 | 平原（1952）、察哈尔（1952）、绥远（1954）、宁夏省（1954）、热河（1955）、西康（1955）、辽东辽西松江（1954）相继撤销；内蒙古大体成今界 |
| 1958—1976 | 广西僮族自治区（1958.3）、宁夏回族自治区（1958.10）、西藏自治区（1965.9）成立；**1969 年内蒙古东部划归黑龙江、吉林、辽宁、宁夏**（1979 恢复） |

- 点击任一历史区划单位可看其构成（按现行县级单位聚合）、该时期说明与当月控制政权。
- **渲染**：历史省份与现行省份使用同一套样式（先按县聚合、再用滤镜补缝并派生统一外轮廓），
  因此不会出现"两种图块"或县界碎缝。
- **口径**：历史省界由**现行县级边界聚合**近似，县级以下差异未细分；
  史料只记"某县一带"者按今县整县近似。数据在 [data/historical_units.json](data/historical_units.json)（含各时期说明），可自行修订。
- 底图按时期自动切换：拖动时间轴跨越时期分界时，省级单位会重新拼装。

## 二、运行方式

### 方式一：Docker（推荐，本机测试）
```bash
docker compose up -d --build      # 构建并启动
# 打开 http://localhost:8780
docker compose logs -f            # 查看日志
docker compose down               # 停止
```
- 端口：宿主机 `8780` → 容器 `8000`（如需改端口，编辑 `docker-compose.yml` 的 `ports`）。
- 镜像内为 Python 标准库静态服务，**零额外依赖**；容器自带 `HEALTHCHECK`。
- 基础镜像使用本机已有的 `python:3.13-slim`，构建过程不访问 Docker Hub。

### 方式二：直接打开单文件
```bash
python3 build.py          # 生成自包含的 index.html
open index.html           # 或双击；离线可用
```

### 方式三：本地静态服务（开发用）
```bash
python3 build.py && python3 -m http.server 8777
# 打开 http://127.0.0.1:8777/index.html  （自检页：/tests/self_test.html）
```

## 四、数据规范

### 势力归属（`data/factions.json`）
```jsonc
{
  "factions": { "qing": { "name": "清王朝", "color": "#c9a227", "desc": "…" } },
  "provinces": { "北京": [ { "from": 1893, "to": 1911, "faction": "qing", "note": "顺天府，直隶总督辖区" } ] },
  "monthOverride": { "1931": [ ["辽宁", 9, "japan", "1931年9月18日九一八事变，日军侵占沈阳"] ] }
}
```
- `provinces` 覆盖 1893—1976 逐年、34 省，区间首尾相接、无缝隙无重叠（构建时强制校验）。
- `monthOverride` 为月级切点：`[省, 月, 势力, 依据]`，只覆盖该年该月及其后；
  未覆盖的月份沿时间轴**正向继承**上一个月（因此 1949 年 10 月的锚点不会倒灌到 1—9 月）。

### 周边国家（`data/neighbors.json`）
```jsonc
{ "factions": { "jp_empire": { "name": "大日本帝国", "color": "#7d5ba6", "desc": "…" } },
  "neighbors": { "日本": [ { "from": 1893, "to": 1945, "faction": "jp_empire", "note": "…" } ] },
  "monthOverride": { "1945": [ ["日本", 9, "allied_occ", "1945年8月15日日本投降，9月起由盟军占领"] ] } }
```
结构与 `factions.json` 相同：年区间打底、月级切点精确到月，构建时强制校验逐年覆盖。

### 事件（`data/events.json`）
```jsonc
{ "year": 1937, "date": "1937年12月13日", "title": "南京大屠杀", "place": "江苏南京",
  "provinces": ["江苏"], "category": "战争", "importance": 3,
  "summary": "…", "detail": "…", "tags": ["…"],
  "sources": [ { "t": "百度百科·南京大屠杀", "u": "https://baike.baidu.com/item/…" } ],
  "deep": { "figures": ["…"], "timeline": [ { "d": "…", "t": "…" } ], "impact": "…", "forcesAtTime": "…" } }
```

## 六、严肃性与口径说明
- 势力归属判定以**省级行政单元的实际控制**为准（以省会等行政中心为主），抗战等交错时期以主要控制方标注，
  并在每段的 `note` 与抽屉「归属依据」中说明；分歧之处（如 1913—1950 年西藏地方治理状态、
  1949 年后两岸分治、新疆三区时期）均已明确标注。
- 底板使用**现行省界**（DataV 原始边界，简化容差 0.002°，各省共享边界保持一致，缩放后不出现缝隙），
  以细描边区分，仅供定位；历史时期省界变动（如热河、察哈尔、绥远、西康等）在事件与说明中处理。
- 周边国家使用 **Natural Earth 1:50m** 国界数据，与中国轮廓之间用蒙版衔接，避免精度差异造成的碎片填充。
- 史料全部取自公开出版物与公开网页（《中国历史地图集》近现代部分、各省地方志、中共党史公开出版物、
  民国史公开研究等），每条事件均附可点击来源；涉台、涉藏表述采用公开出版物规范用语。
- 南海诸岛绘制在同一画布内（海南岛正南、与主图等比例），九段线为公开地图通行走向的示意画法。
- 周边国家着色表示该地当年的实际统治政权或占领方（殖民帝国、占领区、独立国家等），仅作地理与势力对比参照，
  不代表对其内政的评断；邻国事件数据暂未收录。
